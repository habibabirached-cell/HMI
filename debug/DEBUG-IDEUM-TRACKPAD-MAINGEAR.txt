6. COMMON FAILURES
================================================================================

  | Symptom | Cause | Fix |
  |---------|-------|-----|
  | Port 8767 not listening | Mouse server not started / crashed | start-kiosk-mouse-server.bat |
  | websockets import error | Python package missing | pip install websockets |
  | ws-test OK locally, fails from Ideum | Windows Firewall blocking 8767 | Allow inbound TCP 8767 Private |
  | Ideum shows "Mouse bridge offline" | Can't reach ws://192.168.50.1:8767 | Firewall + cable + server running |
  | Connected but no cursor move | Bridge running but SetCursorPos blocked | Run debug bat step 3; check admin/session |

  | Back / Grid Connected slow vs Click fast | Focus went through Docker :5000 relay | Use direct :8766; allow firewall TCP 8766 Private |
  | Grid Connected does not raise Vernova | Browser CORS blocked :8766 fetch | Restart KioskFocusServer (CORS fix); WS focus on :8767 backup |
  | Trackpad stuck while Vernova loads | SetCursorPos synthetic cursor | Bridge uses mouse_event relative (restart KioskMouseServer) |
  | Trackpad jumps when finger lands elsewhere | Absolute x,y mapping on touch down | Relative dx/dy only — hard refresh Ideum UI |
